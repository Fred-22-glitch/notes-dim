# Notes Dim — Privacidade e licença de uso

## Política de privacidade

- O Notes Dim guarda as suas notas somente no seu aparelho e, se você escolher, na pasta do Cofre que você indicar (por exemplo, uma pasta sincronizada pelo Syncthing). Nenhuma nota, desenho ou arquivo é enviado para servidores do Notes Dim ou de terceiros.
- O app não tem conta, login, anúncios, rastreamento nem coleta de dados de uso.
- A única conexão com a internet é a verificação de atualizações: o app consulta a página de versões do projeto no GitHub (api.github.com) para saber se existe uma versão nova e, se você tocar em "Atualizar", baixa o arquivo de instalação de lá. Nessa consulta o GitHub recebe apenas os dados técnicos normais de qualquer acesso (como o endereço IP), conforme a política de privacidade do próprio GitHub.
- Permissões no Android: acesso à pasta que você escolher para o Cofre (dado por você no seletor de pastas do sistema), internet (só para atualizações), vibração (resposta ao toque longo) e instalar atualizações do próprio app (pedido pelo Android na hora de atualizar).
- Os backups automáticos ficam no próprio aparelho: no PC em Documentos/Notes Dim/backups e no Android em Android/data/app.notesdim/files/backups.
- Para apagar todos os dados, desinstale o app e apague a pasta do Cofre e a pasta de backups, se tiver usado.
